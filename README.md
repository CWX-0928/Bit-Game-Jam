# Bit-Game-Jam
-

## 1. Clone the Repository

Repository:  
BIT-GAME-JAM

Open the folder where you want to store the project.

Example:
```bash
C:\Users\Admin\Documents\test
```

Open Command Prompt inside the folder:
```bash
cmd
```

Clone the repository:
```bash
git clone https://github.com/CWX-0928/Bit-Game-Jam.git
```

---

## 2. Open the Project in Godot

1. Open Godot
2. Click **Import**
3. Select the cloned project folder

---

## 3. Switch to Your Branch

Open terminal inside the project folder and run:

```bash
git checkout branch-CWX
```

If the branch does not exist locally yet:

```bash
git checkout -b branch-CWX origin/branch-CWX
```

---

## 4. Update the Project

Pull the latest changes from the `main` branch:

```bash
git pull origin main
```

---

## 5. Upload Your Changes

### Step 1 — Add Files

```bash
git add .
```

### Step 2 — Commit Changes

```bash
git commit -m "Your commit message"
```

Example:
```bash
git commit -m "Added enemy movement system"
```

### Step 3 — Push Changes

```bash
git push
```
